# Editorial Instinct & Physicalization

## Why AI Storyboards Become Slides
LLMs often map a script word directly to a literal image or generic icon. That creates static, low-specificity visuals:
- “market dominance” -> pie chart;
- “bottleneck” -> padlock;
- “platform” -> floating app icons;
- “decline” -> downward arrow;
- “rejection” -> two stock people talking.

Strong editorial direction asks: **what physical relationship, mechanism or consequence is actually happening?**

## The Physicalization Algorithm
For each abstract claim:

### Step 1 — State the editorial meaning
What should the viewer believe/understand after this beat?

### Step 2 — Name the real mechanism
Examples:
- monopoly -> supply/control concentrated through one gate;
- network effect -> each new participant increases value/traffic for others;
- technical debt -> one change propagates expensive downstream work;
- market rejection -> one party refuses a transfer/offer;
- platform switch -> an old route/system is abandoned for a new one.

### Step 3 — Find the story's material vocabulary
Use objects that belong to the world:
- phones, keypads, app tiles, signal paths;
- ships, ports, straits, containers;
- chips, wafers, fabs, routes;
- documents, cash, storefronts, lamps;
- maps, roads, bridges, queues;
- UI panels, cursors, timelines.

### Step 4 — Select the visual relationship
Choose an operation:
`transform / route / jam / split / accumulate / replace / detach / reveal / illuminate / collapse / assemble / transfer / compare / orbit / funnel / decay`.

### Step 5 — Write the mute thesis
“Without narration, the viewer can understand that ______.”

If the blank can only be filled with a sentence copied from the narration, the visual is probably too textual.

## Metaphor Quality Tests
A good metaphor is:
- specific to this story;
- easy to read muted;
- visually performative;
- truthful about the underlying relationship;
- compatible with available assets;
- distinct from neighboring scenes.

A weak metaphor:
- is a generic icon;
- implies false causality;
- requires explanatory text to work;
- looks impressive but does not clarify the beat;
- depends on a literal reading of domain jargon.

## Force Pair Heuristic
Many scenes benefit from two meaningful forces, but not necessarily conflict:
- old state vs new state;
- flow vs capacity;
- subject vs obstacle;
- signal vs noise;
- growth vs burden;
- promise vs outcome;
- object vs environment;
- evidence vs assumption.

When real conflict exists, a Tension Triangle can be useful:
`Actor -> Counter-force -> Stakes`.
It is optional.

## Micro-Pacing Without a Stopwatch Formula
Think in semantic states rather than fixed durations:
1. orient;
2. disturb/change;
3. land the consequence;
4. hand attention onward.

A 4-second scene may have all four. A 12-second scene may contain several disturbances before payoff. Intentional stillness is valid when the viewer is processing a reveal or anticipating action.

## Focal Continuity
For each scene ask:
- where does the eye begin?
- where does it finish?
- what direction is visual momentum moving?
- what scale are we at?
- can the next scene begin from that position/direction/object?

Good continuity can be:
- positional match;
- direction continuation;
- shape/object match;
- color/line continuation;
- macro-to-micro or micro-to-macro contrast;
- portal through a meaningful object.

## Examples of Better Translation
These are illustrative patterns, not templates.

| Abstract idea | Weak generic visual | Stronger direction pattern |
|---|---|---|
| dominant supplier | pie chart only | repeated downstream objects physically funnel through one supplier/gate |
| software fragmentation | Matrix code | one change branches into many incompatible paths/devices |
| ecosystem momentum | app icon cloud | apps/users/developers circulate through a reinforcing loop while late entrant fails to close the loop |
| debt burden | money bag | physical obligations accumulate until they outweigh/obstruct productive assets |
| late pivot | turning arrow | bridge/lane/system assembles after existing traffic has already committed elsewhere |
| rejection | boardroom stock photo | tangible offer travels toward recipient and is physically pushed/returned/blocked |
| business model reversal | lightbulb | old rules/props are crossed out/replaced one by one with new operating rules |

## Editorial Honesty
A metaphor can simplify complexity but cannot secretly become evidence. If a visual looks like a real historical document, quote, exact statistic or factual screenshot, it must be sourced and claim-backed.
