# Technique Library — Reusable Directing Moves v0.6

These are **optional primitives**. Select them because they solve a semantic or compositional problem, not because a benchmark used them.

## Spatial / Camera

### Weld-and-Detach Portal
A frame/photo/screen/document moves as one unit with the camera, then foreground and embedded content separate during the push-through. Useful when one object genuinely becomes the next environment.

### Differential Depth Punch
Foreground scales/translates more aggressively than background. Add occlusion/contact shadow to ground the foreground layer.

### Macro-to-System Reveal
Start on a tiny detail, pull back to expose the whole system. Good for “this small component controls everything” stories.

### System-to-Macro Dive
Start on map/network/system, dive into one node/object where the next causal mechanism lives.

### Continuous Kinetic Stage
Keep one world/timeline in a large virtual canvas and move camera between milestones instead of hard-cutting every beat.

### Focus Hunt / Inspection
Momentarily rack focus, blur, or search before locking onto evidence. Works when the narrative implies investigation or uncertainty.

## Prop / Object

### Staggered Cascade
Repeated documents/cards/photos enter from different directions/rotations and settle in semantic order.

### Object-as-Chart
Use repeated physical objects as bars, stacks, counters or proportions. Only use exact quantitative geometry when backed by verified data.

### Damped Gesture
Pointer/hand/needle wags or swings with decaying oscillation so the gesture resolves.

### Physical Replacement
Old layer slides/folds/detaches while new layer occupies the same physical footprint.

### Assembly / Lock
Parts arrive and snap/lock into place. Useful for partnerships, components, product systems and processes.

### Failure Cascade
One intervention propagates visible failure through connected objects. Use only when the causal relationship is truthful or clearly metaphorical.

### Hold-Keyframe Flicker
Discrete light/value states rather than smooth fades; useful for neon, relays, cash highlights, alarms, old displays.

## Graphic / Evidence

### Marker Swipe / Underline
A hand-drawn/highlight stroke tracks a short phrase, number or evidence detail. Avoid using it on every sentence.

### Count-Up / Mechanical Counter
Numbers accumulate to a meaningful verified endpoint. Prefer a physical context when possible.

### Path Draw / Route Trace
Animate line reveal along geography/process/network. Let moving tokens/objects prove flow rather than decorative particles alone.

### Evidence Crop / Zoom
Crop into a real chart/document/screenshot, trace the relevant area, and retain enough context to avoid misleading the viewer.

### Split Behavioral Comparison
Two sides perform the same operation differently rather than simply showing two static columns.

## Light / Atmosphere

### Swinging Light Cone
Lamp rotates while its cone/spill follows and reveals different objects. The lighting change should alter story hierarchy.

### Moving Spotlight
A spotlight finds/reveals evidence or subject hierarchy. Do not use as generic theatrical decoration.

### Print Registration Jitter
Tiny deterministic misalignment between print layers. Use only in print/editorial style worlds.

### Posterized Motion
Snap continuous motion to a lower temporal cadence while rendering at the project FPS. Good for handmade/editorial stop-motion feel, not universal quality.

### Gate Weave
Small deterministic frame jitter mimicking mechanical film transport. Optional vintage treatment.

### Character Boil
Tiny stepped breathing/sway/scale variations keep static cutouts alive.

## Scene-Level Selection Rule
Before choosing a technique, answer:
1. What semantic operation does the scene require?
2. What material world does the story inhabit?
3. What focal handoff must occur?
4. Which neighboring technique should be avoided to preserve construction variety?
5. Can the same effect be achieved more simply?

Prefer one signature technique plus a few supportive motions.
