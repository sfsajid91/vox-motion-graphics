# Creative Scene Engine v0.6

## Purpose
Turn semantic story beats into scenes that feel **directed** rather than merely illustrated.

## Editorial Translation First
Before choosing motion, answer:
1. What must the viewer understand after this beat?
2. What is the real mechanism / relationship underneath the language?
3. What material objects, processes, spaces or forces belong to this story world?
4. What visible state change can embody that mechanism truthfully?

Do not map nouns directly to icons. A monopoly is not automatically a lock; debt is not automatically a money bag; software complexity is not automatically scrolling code.

## Visual Sentence
Default grammar:

`Anchor -> Action / Escalation -> Consequence / Payoff -> Launchpad`

- **Anchor:** establish the minimum world/state needed for orientation.
- **Action:** meaningful state change: transform, collide, accumulate, route, reveal, block, detach, etc.
- **Consequence:** visual proof/emotional landing of the beat.
- **Launchpad:** leave the eye/object/momentum positioned for the next scene.

This grammar is semantic, not time-boxed. Do not force fixed 1.5s/2s/1.5s segments.

## Scene Mechanism Library
Choose the mechanism that best explains the beat.

### Transformation
A becomes B. Useful for category shifts, upgrades, redefinitions, physical-to-digital transitions.

### Cause -> Effect
A visible trigger produces a visible consequence. Useful for cascading failures, pressure, policy effects, system dependencies.

### Flow / Route / Journey
Trace movement through geography, process, network, supply chain or time.

### Accumulation / Multiplication
One becomes many until scale, burden or momentum is felt physically.

### Bottleneck / Constraint
Objects funnel, jam, queue, split, narrow or fail to connect.

### Comparison / Counter-Motion
Two systems perform the same job differently. Prefer behavior over static two-column slides.

### Evidence Inspection
A real chart/document/screenshot/map becomes the environment. Zoom, highlight, trace and annotate only what the source actually supports.

### Object-as-Chart
Real or reconstructed objects physically embody quantities instead of drawing a generic bar/line when a more tactile form is clearer.

### Portal / Weld-Detach
A frame, photo, display, document or map becomes the next environment. Use when the transition also advances meaning.

### Layered Depth Punch
Differential foreground/background scaling, grounded shadows and occlusion create 2.5D depth.

### Prop Choreography
Papers, tools, hands, labels or objects enter in semantic order and physically perform the narration.

### Light / Focus Reveal
A lamp, spotlight, focus plane or exposure change reveals importance, value, danger or hidden evidence.

### Continuous Camera Route
The camera travels through a coherent world/timeline/process; each stop reveals something new.

### Gesture / Character Reaction
A gesture carries an emotional turn: rejection, warning, approval, disbelief, celebration, regret.

### State Loss / Decay
Connections, occupancy, color, light, structural integrity or traffic drains away.

### Recontextualization
The same object is revealed to have a different role/meaning than the viewer assumed.

### Network / Flywheel
Users, developers, money, products, influence or information reinforce one another through loops.

### Replacement / Handoff
One physical system exits while another persists; useful for ownership changes, platform shifts and succession.

## Optional Conflict Grammar: Tension Triangle
Use only if the story contains real conflict:
- Actor
- Counter-force
- Stakes / breaking point

Do not invent a villain just to animate a beat.

## Metaphor Ladder
Try in order:
1. literal mechanism/evidence if visually strong;
2. functional process;
3. spatial/system diagram;
4. tactile physical metaphor;
5. generic symbolic icon only if better options fail.

## Concept Search
For medium/high uncertainty, create 2–4 concept cards across **different construction families**. Each card contains:
- semantic job;
- visual thesis;
- construction family;
- mechanism;
- anchor/action/consequence/launchpad;
- signature moment;
- entry/exit focal zone;
- 2–5 asset roles;
- continuity handoff;
- representation type;
- production feasibility;
- biggest risk.

Select internally using:
- mute clarity;
- specificity to this story;
- motion potential;
- factual/representation honesty;
- asset feasibility;
- attention continuity;
- visible distinctness from neighboring scenes.

## Attention / Gaze Continuity
Plan every scene as a handoff of attention.

Track a coarse 3x3 focal zone:
`top-left | top-center | top-right | mid-left | center | mid-right | bottom-left | bottom-center | bottom-right`

Record:
- entry focal zone;
- exit focal zone;
- dominant motion direction;
- scale class: macro / medium / micro;
- continuity object/line if any.

The next scene should usually:
- originate near the previous exit focal zone;
- continue momentum or deliberately reverse it for emphasis;
- carry a recurring line/object/shape; or
- use a deliberate macro<->micro scale contrast.

This is not a mandate to center everything.

## Composition Taste Heuristics
- one dominant focal point per micro-state;
- centering is intentional, not automatic;
- foreground occlusion anchors flat cutouts;
- strong scale contrast communicates hierarchy;
- negative space should serve captions, action or anticipation;
- environment/material world should influence surfaces and props;
- alternate macro/micro scale when it improves rhythm;
- camera movement must discover or reframe information;
- repeated objects should vary entry direction/rotation/settle;
- intentional holds are allowed when they build tension or let a payoff land.

## Anti-Template Rule
Reuse code rigs when narrative geometry matches. Change visible composition, semantics, assets and focal flow. Reuse the mechanism—not the shot.
