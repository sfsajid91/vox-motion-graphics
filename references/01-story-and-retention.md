# Story & Retention Planning

## Story Before Motion
A topic is not a story. Find the angle, viewer promise and logic before discussing Remotion.

Strong narrative engines include:
- contradiction / paradox
- hidden mechanism
- before -> reversal -> after
- underestimated challenger
- mistake -> compounding cost
- race / bottleneck / constraint
- mystery -> evidence -> reveal
- process -> failure point -> consequence
- system that behaves opposite to intuition

Do not force scandal, rivalry or downfall when unsupported.

## Build a Logical Spine
Examples:
`event -> reaction -> mechanism -> consequence -> escalation -> payoff`

or:
`question -> evidence -> model -> implication -> answer`

If the arrows are weak, the eventual visual plan will become a list of disconnected illustrations.

## Retention Map
For each semantic beat record:
- viewer question entering the beat
- beat answer / narrative function
- viewer question leaving the beat
- emotion/state change
- visualizable nouns
- active verbs
- quantities / evidence objects
- claim IDs where factual

A strong beat changes what the viewer knows or expects.

## Voiceover as Visual Source Code
Extract from narration:
- **nouns** -> people, places, props, evidence, materials
- **verbs** -> possible motion and physical action
- **contrasts** -> possible composition geometry
- **numbers** -> possible data or physical scale
- **metaphors already present in language** -> possible signature scene mechanism
- **emotional words** -> motion cadence and sound energy

Do not simply visualize each noun literally. Use the words to find what the scene should *do*.

## Narration Rules
- concrete nouns and active verbs
- no generic filler
- numbers only when they change the story
- abstract mechanisms explained through consequences/objects
- camera directions never spoken
- ending should complete/reframe the opening
- avoid generic moralizing if the visual payoff can carry the conclusion

## Duration
Duration is audio-driven. Use WPM only as a planning envelope. Final boundaries follow recorded/synthesized narration.

## Fact Discipline
For factual work, consume the claim set. Exact numbers/quotes/motives/causal accusations require adequate verification. A stronger hook never justifies making a claim more specific than the evidence.
