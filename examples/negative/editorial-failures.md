# Editorial failures and recoveries

These synthetic failures are diagnostic patterns, not universal bans. Use the recovery when the symptom matches.

## 1. Effects become the subject

- **Failure:** Grain, parallax, wobble, light leaks, and labels compete before the viewer understands the event.
- **Why it fails:** More treatment cannot repair an unclear factual sentence.
- **Recovery:** Remove layers until the subject, action, and consequence read without decoration; reintroduce only supporting treatment.

## 2. Technical success is mistaken for editorial success

- **Failure:** The scene renders, typechecks, uses valid assets, and still feels awkward or empty.
- **Why it fails:** Technical QA proves execution, not hierarchy, meaning, pacing, or visual continuity.
- **Recovery:** Run a separate editorial critique on representative frames and a motion preview.

## 3. Static image plus slow zoom carries the whole beat

- **Failure:** Narration advances through several ideas while an archival still only drifts or scales.
- **Why it fails:** The visual structure does not acknowledge changes in cause, state, or stakes.
- **Recovery:** Introduce a meaningful reveal, evidence inspection, spatial relationship, transformation, or handoff. Keep a still hold only when sustained attention is intentional.

## 4. A continuous process becomes repeated cards

- **Failure:** Each step receives a new rectangle, icon group, or title card.
- **Why it fails:** The viewer sees a list rather than a system.
- **Recovery:** Preserve an object, line, material, or camera path across steps so cause and effect remain connected.

## 5. Narration changes while the visual state does not

- **Failure:** New claims arrive, but composition, focal point, and object relationships remain unchanged.
- **Why it fails:** Motion is present without semantic progression.
- **Recovery:** Map each rhetorical turn to a meaningful state change or declare the hold intentional because the same image is still doing useful work.

## 6. Labels explain what the action already shows

- **Failure:** UI badges and instruction words repeat visible actions.
- **Why it fails:** Equal-weight annotations weaken the focal point and make the scene feel like a planning document.
- **Recovery:** Keep only facts, evidence labels, or thesis copy that adds information unavailable from the action.

## 7. A palette swap pretends to be a transition

- **Failure:** The colors change, but object state, camera behavior, and editorial meaning do not.
- **Why it fails:** Surface variation is not narrative progression.
- **Recovery:** Pair color change with a cut, transformation, viewpoint change, or other legible state transition.

## 8. The storyboard becomes a runtime replica

- **Failure:** Preview UI exposes counters, tuning controls, and implementation parameters that do not help approve the design.
- **Why it fails:** The decision surface becomes harder to review and more expensive to maintain.
- **Recovery:** Animate only what is needed to judge composition, hierarchy, assets, motion, transitions, pacing, and readability. Document implementation-only behavior in notes.

## 9. A generated prop implies false evidence

- **Failure:** A synthetic object is presented as if it were an authentic historical artifact.
- **Why it fails:** Plausibility is mistaken for provenance.
- **Recovery:** Mark it as reconstruction, replace it with verified evidence, or use a neutral programmatic representation.

## 10. The composition outlives the voiceover

- **Failure:** Narration and captions finish while the video continues without new action or an intentional hold.
- **Why it fails:** A technically valid duration reads as dead air.
- **Recovery:** Reconcile voiceover end, caption end, scene end, transitions, and final hold using measured timestamps.

## 11. The thesis frame is more complex than the explanation

- **Failure:** The final claim is surrounded by every supporting object and decorative cluster.
- **Why it fails:** Proof competes with payoff.
- **Recovery:** Keep the minimum contrast needed to understand the thesis and let negative space establish priority.

## 12. A local panel breaks the visual world

- **Failure:** A nested screen or component uses its own default background, crop, or side bars at the transition.
- **Why it fails:** Isolated component correctness does not guarantee scene continuity.
- **Recovery:** Inspect exact transition frames and make background ownership explicit at the composition level.
